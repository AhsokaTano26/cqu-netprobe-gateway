# 楼栋代号（部署参考）

这份列表有两个用途：

1. 在 `/admin/buildings` 的**批量导入**里，按校区一批一批粘贴；
2. 作为 `building` 与 `building_group` 两个 Prometheus Label 的对照表——
   看板上出现 `building="zy05"` 时，在这里查它对应哪栋楼。

**代号创建后不可修改。** 它进 `building` Label，也进 `probe_id`（形如
`{校区}-{楼栋}-{6位随机}`），改名会让 Prometheus 的历史时序断裂。

共 5 个校区、70 栋。

---

## 导入方法

到 `/admin/buildings` 最下方的「批量导入」：

1. **校区**选下面对应的那个；
2. **统一楼栋群两个框留空**——每行都写了完整的 4 个字段，不需要默认值；
3. 粘贴该校区整段内容，点导入。

已存在的代号会被**跳过而不是覆盖**，所以改正错误后整份重新粘贴是安全的。
这也意味着**列表更新后重新粘贴整段即可**，只会补上新的那些。

## 命名约定

**楼栋代号**：小写字母、数字、下划线，≤16 位，全站唯一（不区分校区）。

```text
A/B/C 区宿舍    a01…a12 / b01…b12 / c01…c05     校区字母 + 两位序号
虎溪各园        jy01 / my01… / sy01… / zy01… / ly01… / hy01…
                园名拼音首字母 + 两位序号
单体楼栋        acd（ACD 楼）、xuelin（学林宾馆）、qj（青教楼）
两江            lj01、lj02
```

**楼栋群**把多栋楼聚合成一个园区或功能区，用于看板上按区域聚合
（`sum by (campus, building_group)`）。虎溪按园划分，A/B/C 区按功能划分。

楼栋群显示名同样进 Label，**手打新值会产生无法合并的 Series**——
导入时用这里的固定写法，不要临时改字。

---

## 导入前确认三件事

1. **校区代号。** 表中的 `spba` / `spbb` / `spbc` / `hx` / `lj` 是按现有部署写的，
   导入前到 `/admin/campuses` 核对一眼。导错校区后楼栋不会自动搬家——校区不可改。
2. **已存在的楼栋不会被覆盖。** 某代号若已建过，导入会报「已存在，跳过」并**保留
   原样**，包括它原来的显示名与楼栋群。要统一的话，导入后逐个编辑。
3. **导入后回看一次。** 确认每个校区的分组标题里栋数正确、没有多出空分组。

---

## 与探针的关系

楼栋代号出现在 `probe_id` 里：注册探针时选定校区与楼栋，Gateway 生成
`{校区}-{楼栋}-{6位随机}`。所以**这份列表同时是探针注册页下拉菜单的内容来源**——
每加一栋楼，注册页就多一个选项。
